# 物流工单控制台

把微信群聊天消息持续整理成可追踪、可追溯的物流与服务工单。单文件网页，双击即用，无需构建。

## 在线预览

<https://logistics-ticket-console.app.workbuddy.host/?sharecode=D22JKAMYR2>

## 能做什么

- 群聊粘贴提炼：识别车牌、订单号、金额、@责任人、待核实 / 逾期 / 矛盾关键词，生成可编辑工单
- 五大队列：待处理 / 即将到期 / 已逾期 / 待核实 / 已完成
- 多维筛选：责任人、群组、客户、车辆、订单、状态 + 全文搜索
- 工单详情：基本信息、未解决矛盾、证据编号、时间线、原始消息引用、历史版本
- 合并与追溯：后续消息合并进同一工单，版本递增、保留历史快照
- 跨群汇总：按群组统计状态分布、跨群转派、待核实、未解决矛盾
- 待核实原则：物流轨迹、外部报价、双方说法等未经确认的信息统一标记，不作为事实依据
- 双端适配：电脑端表格 / 手机端卡片，同一文件响应式

## 本地运行

直接用浏览器打开 `logistics-ticket-console.html` 即可。

数据保存在浏览器 `localStorage`。恢复初始示例数据：控制台执行
`localStorage.removeItem('logi_tickets_v1')` 后刷新。

## 接入

数据结构预留证据编号、原始消息、矛盾、跨群、版本、时间线等字段，跟进记录标注 ERP / 助手接口，便于替换为后端 API。
