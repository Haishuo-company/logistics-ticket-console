# 物流工单控制台

把微信群聊天消息、手机通知持续整理成可追踪、可追溯的物流与服务工单。支持电脑网页、手机网页和 Android APK，数据统一存服务端。

## 在线地址

<https://logistics-ticket-console.app.workbuddy.host/?sharecode=D22JKAMYR2>

首次打开用 `admin / admin123` 登录，登录后请在「管理后台」改密码。

## 三个入口

| 入口 | 说明 |
|---|---|
| 在线网页 | 上面的链接，电脑 / 手机浏览器直接打开 |
| Android APK | `物流工单控制台.apk`，装到手机即用；顶部标题栏可改服务器地址 |
| 本地运行 | `npm start`，然后访问 `http://localhost:3000` |

## 能做什么

- 群聊粘贴提炼：识别车牌、订单号、@责任人、待核实 / 逾期 / 矛盾关键词，生成可编辑工单
- HaishuoClaw 通知转工单：从手机通知云端拉取，按规则提炼成工单草稿，确认后入库
- 五大队列：待处理 / 即将到期 / 已逾期 / 待核实 / 已完成
- 多维筛选：责任人、群组、客户、车辆、订单、状态 + 全文搜索
- 工单详情：未解决矛盾、证据编号、时间线、原始消息引用、历史版本
- 合并与追溯：后续消息合并进同一工单，版本递增、保留历史快照
- 跨群汇总：按群组统计状态分布、跨群转派、待核实、未解决矛盾
- 待核实原则：轨迹、报价、双方说法等未经确认的信息统一标记，不作为事实依据

## 用户与权限

「管理后台 → 用户管理」可增删用户、设置角色（管理员 / 成员）和可见群组。

- 管理员：全部工单 + 用户管理 + 通知密钥配置
- 成员：按「可见群组」隔离，只能看到自己负责或所在群组的工单

## HaishuoClaw 密钥配置

密钥不硬编码、不进仓库。首次使用：管理后台 → 通知设置 → 填手机号和 key。

key 来源：手机 HaishuoClaw App → 关于页 → 复制提示词，取 `key=` 后面那串。
服务端代理调用云端 API，密钥不下发到前端。

## 技术结构

- `server.js`：零依赖 Node 服务（http + JSON 文件存储 + 静态托管），单端口可发布
- `public/index.html`：前端单页（响应式，API 驱动）
- `android/`：Android WebView 套壳工程
- `data/`：运行时生成（gitignore，不入库）

## 本地开发

```bash
npm start
# 默认 admin / admin123
```

数据存 `data/db.json`。恢复初始数据：删掉该文件后重启。

## 接入预留

数据结构含证据编号、原始消息、矛盾、跨群、版本、时间线等字段，跟进记录标注 ERP / 助手接口，便于替换为正式数据库与 ERP 对接。
